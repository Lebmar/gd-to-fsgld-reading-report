## 这份报告是什么

这是 XProgram 科研项目第一阶段的**文献阅读报告**（2026 年 9 月），整合两份材料：

1. Royer 关于随机梯度方法的讲义
2. Bruno et al. 提出 fSGLD（Flatness-Aware Stochastic Gradient Langevin Dynamics）的论文

报告沿 GD → SGD → SGLD → fSGLD 的顺序展开，每一阶段都是下一阶段的基础。核心线索是：**对待噪声的态度在演化**——无噪声 → 容忍噪声 → 设计噪声 → 赋予噪声几何结构。

## 四个阶段

| 算法 | 对噪声的态度 | 特性 | 主要弱点 |
|---|---|---|---|
| **GD** | 无噪声 | 精确、确定；强凸下几何收敛 | 每步 O(n) 成本；非凸下无法逃离坏的局部极小 |
| **SGD** | 容忍噪声 | 单样本估计，成本降 n 倍 | 存在方差税，恒定步长下只能收敛到**噪声地板**的邻域 |
| **SGLD** | 设计噪声 | 不变测度为 Gibbs 分布 e^(-βu)，同时是优化器与后验采样器；自带不确定性估计 | 混合慢；恒定步长下有离散化偏差；**对损失面几何无偏好** |
| **fSGLD** | 噪声带几何结构 | 梯度在扰动点求值，获得隐式的 Hessian-trace 正则化，偏好平坦极小 | 正则强度与温度耦合；tr H 非重参数化不变；各层尺度被各向同性扰动同等对待 |

## 核心推导：扰动梯度为什么偏向平坦极小

fSGLD 与 SGLD 的唯一区别是**梯度在扰动点 θ+φ 处求值**（φ ~ N(0, σ²I)）。

第一步，定义随机平滑代理目标 g_σ(θ) = E_φ[u(θ+φ)]，则扰动点梯度是 ∇g_σ 的无偏估计——fSGLD 等价于在 g_σ 上跑标准 SGLD。

> 直觉图像：标准 SGLD 用一个几何点去感知地形，fSGLD 则是**滚一个半径为 σ 的球**，球感受到的是它覆盖范围内的平均损失。窄而尖的盆地会被周围的高地填平，宽盆地几乎不变。

第二步，对 u(θ+φ) 做 Taylor 展开并对 φ 取期望：

```
g_σ(θ) = u(θ)            ← 原目标
        + (σ²/2)·tr H(θ)  ← 曲率惩罚
        + E[R(θ,φ)]       ← 余项 O(σ⁴d²)
```

一阶项因 E[φ]=0 消失，三阶项因对称分布的奇次矩为零消失，二阶项由独立性直接算出 E[φᵀHφ] = σ²·tr H。**这正是目标 v(θ) = u(θ) + (σ²/2)·tr H(θ) 中的正则项**——fSGLD 因此在不接触二阶信息的情况下隐式地优化了 v。

## 耦合条件 σ = β^(-(1+η)/4) 的逻辑

- 不变测度 π ∝ e^(-βg_σ)，理想目标 ∝ e^(-βv)，两者之比由 e^(βE[R]) 控制
- `β·E[R] ~ βσ⁴d² = β^(-η)d² → 0` 要求 **η > 0**（余项必须消失）
- `βσ² = β^((1-η)/2) → ∞` 要求 **η < 1**（偏置必须存活）

η ∈ (0,1) 的两端各堵住一种失效模式。fSGLD 因此与标准 SGLD 拥有**同样多的超参数：只有 β**。

## 我的三点批评（独立判断）

1. 正则强度被耦合条件焊死在温度上（βσ² = β^((1-η)/2)）——强的平坦性偏好必须依赖大 β
2. **tr H 在网络的重参数化下并非不变量**，而各向同性扰动 N(0, σ²I) 对尺度差异极大的不同参数层一视同仁
